# WB签到助手（Android）

WorkBuddy 每日签到的安卓客户端。多账号管理、一键签到、定时自动签到、积分/额度查询、派猫猫旅行——把每天手动签到这件事交给手机。

> 本项目为独立开发的第三方辅助工具，与 WorkBuddy 官方无任何关联。
> **仅供学习研究使用**，请勿用于商业用途；因使用本软件产生的一切后果由使用者自行承担。

## 功能

- **多账号管理**：WorkBuddy 账号（含国际版）添加与管理，账号库 JSON 与桌面版互通
- **一键签到**：所有国内版账号一次全签
- **自动签到**：每日定时（可设多个时间点 + 随机延迟）+ 每天首次打开自动补签，双通道兜底
- **积分到期提醒**：每天首次打开时只读检查，7 天内将要过期的积分发通知 + 首页提示条，积分用掉自动撤回
- **积分 / 额度查询**：与官网同口径（summary 聚合为权威、过期包不计入）
- **派猫猫旅行**：自动派发 / 领奖，页面停留期间自动刷新
- **每日 token 保活**：登录凭证快过期自动换新，登录一次长期有效
- **签到日志 / 导入导出 / 内置说明书与隐私协议**

## 隐私

- **零收集**：不注册、无统计 SDK、无广告 SDK、无自有服务器
- 账号 token 仅保存在应用私有目录，卸载即全部清除
- 网络请求只发往 WorkBuddy 官方域名，数据只在你手机与官方服务器之间流动

详见应用内「设置 → 帮助与协议 → 隐私协议」。

## 构建

- Android Studio（推荐）：打开工程根目录，直接 Run
- 命令行：JDK 17 + Android SDK 34，`./gradlew assembleRelease`（首次建议 `gradle wrapper` 生成 wrapper 或使用本机 Gradle 8.7）

```bash
# 使用本机 Gradle 8.7 的示例
gradle assembleRelease --no-daemon
```

产物：`app/build/outputs/apk/release/app-release.apk`

## 使用提示

- 首次添加账号请在官方登录页使用**手机号验证码登录**（微信授权后无法返回原页面，属官网移动端流程限制）
- 国产 ROM（小米/华为/OPPO/vivo 等）请开启「自启动」并将电池策略设为「无限制」，否则定时任务可能被推迟（推迟后仍会补签）
- 详细说明见应用内「设置 → 帮助与协议 → 使用说明书」
